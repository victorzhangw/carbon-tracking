# 即時語音互動系統 - Phase 1 測試指南

## 📋 測試概述

本指南提供 Phase 1 新功能的完整測試步驟和驗證方法。

## 🎯 測試環境

### 系統需求

- Python 3.8+
- Flask + SocketIO
- 現代瀏覽器（Chrome/Edge 推薦）
- 麥克風設備
- 網路連接

### 啟動服務

```bash
# 1. 啟動後端服務
python app.py

# 2. 訪問測試頁面
# 國語版：http://localhost:5000/voice_interaction_realtime/nofish
# 閩南語版：http://localhost:5000/voice_interaction_realtime/roy
```

## 🧪 功能測試

### 1. 語音波形視覺化測試

#### 測試步驟

1. 打開國語版頁面
2. 點擊「開始對話」按鈕
3. 允許瀏覽器訪問麥克風
4. 觀察波形區域

#### 預期結果

✅ **靜音狀態**：

- 顯示靜態波形線
- 顯示「等待語音輸入...」文字

✅ **說話狀態**：

- 波形條動態變化
- 顏色為紫色漸層
- 音量指示器顯示百分比（0-100%）
- 音量條顏色隨音量變化：
  - 綠色：0-30%
  - 橙色：30-70%
  - 紅色：70-100%

#### 測試案例

| 測試項目 | 操作     | 預期結果             |
| -------- | -------- | -------------------- |
| 靜音顯示 | 不說話   | 靜態波形             |
| 小聲說話 | 輕聲說話 | 小幅波形，綠色音量條 |
| 正常說話 | 正常音量 | 中等波形，橙色音量條 |
| 大聲說話 | 提高音量 | 大幅波形，紅色音量條 |

### 2. 對話歷史記錄測試

#### 測試步驟

1. 開始對話並進行 3-5 輪互動
2. 點擊「結束對話」
3. 查看右側歷史側邊欄
4. 點擊歷史項目
5. 點擊清除按鈕

#### 預期結果

✅ **自動儲存**：

- 結束對話後自動出現在歷史列表
- 標題為首句前 30 字
- 顯示相對時間（剛剛/X 分鐘前/X 小時前）

✅ **查看對話**：

- 點擊歷史項目後，對話區顯示完整對話
- 訊息格式與原對話一致
- 包含時間戳記和情緒標籤

✅ **清除歷史**：

- 點擊垃圾桶圖示
- 彈出確認對話框
- 確認後歷史列表清空

#### 測試案例

| 測試項目 | 操作          | 預期結果          |
| -------- | ------------- | ----------------- |
| 儲存對話 | 結束對話      | 出現在歷史列表    |
| 查看對話 | 點擊歷史項目  | 顯示完整對話      |
| 多次對話 | 進行 5 次對話 | 列表顯示 5 條記錄 |
| 清除歷史 | 點擊清除按鈕  | 歷史列表清空      |
| 持久化   | 刷新頁面      | 歷史記錄仍存在    |

## 🐛 常見問題排查

### 問題 1：波形不顯示

**可能原因**：

- 麥克風權限未授予
- AudioContext 未初始化
- Canvas 元素未找到

**解決方法**：

1. 檢查瀏覽器控制台錯誤
2. 確認麥克風權限已授予
3. 刷新頁面重試

### 問題 2：歷史記錄不保存

**可能原因**：

- localStorage 被禁用
- 瀏覽器隱私模式
- localStorage 容量已滿

**解決方法**：

1. 檢查瀏覽器設定
2. 退出隱私模式
3. 清除部分歷史記錄

### 問題 3：快速按鈕無反應

**可能原因**：

- 會話未啟動
- WebSocket 連接斷開
- 後端服務異常

**解決方法**：

1. 確認已點擊「開始對話」
2. 檢查網路連接
3. 查看後端日誌

### 問題 4：音量/語速不生效

**可能原因**：

- AudioContext 未正確初始化
- 音頻節點連接錯誤
- 設定未保存

**解決方法**：

1. 刷新頁面重試
2. 檢查瀏覽器控制台
3. 清除 localStorage 重置設定
