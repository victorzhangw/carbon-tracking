### 2. 後端 API 擴充

#### 2.1 新增 API 端點

```python
# 建議新增的 API
POST   /api/audiobook/bookmark          # 添加書籤
GET    /api/audiobook/bookmarks/:id     # 獲取書籤列表
DELETE /api/audiobook/bookmark/:id      # 刪除書籤

POST   /api/audiobook/progress          # 更新進度
GET    /api/audiobook/progress/:id      # 獲取進度

POST   /api/audiobook/playlist          # 創建播放列表
GET    /api/audiobook/playlists         # 獲取播放列表
PUT    /api/audiobook/playlist/:id      # 更新播放列表

GET    /api/audiobook/statistics        # 獲取統計資訊
```

#### 2.2 資料庫擴充

```sql
-- 建議新增的資料表

-- 書籤表
CREATE TABLE audiobook_bookmarks (
  id INTEGER PRIMARY KEY,
  book_id TEXT NOT NULL,
  chapter_id TEXT NOT NULL,
  position REAL NOT NULL,
  note TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 播放進度表
CREATE TABLE audiobook_progress (
  id INTEGER PRIMARY KEY,
  book_id TEXT NOT NULL,
  chapter_id TEXT NOT NULL,
  position REAL NOT NULL,
  total_duration REAL,
  last_played TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(book_id)
);

-- 播放列表表
CREATE TABLE audiobook_playlists (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 播放列表項目表
CREATE TABLE audiobook_playlist_items (
  id INTEGER PRIMARY KEY,
  playlist_id INTEGER NOT NULL,
  book_id TEXT NOT NULL,
  chapter_id TEXT,
  sort_order INTEGER,
  FOREIGN KEY (playlist_id) REFERENCES audiobook_playlists(id)
);
```

## 📝 結論

AI 廣播劇系統具有很大的優化空間，建議採用分階段實作的方式，優先完成核心功能優化，再逐步添加進階功能。重點應放在：

1. **播放體驗優化**：這是核心功能，直接影響使用者滿意度
2. **進度管理**：讓使用者能輕鬆追蹤閱讀進度
3. **介面現代化**：提升視覺吸引力和專業度
4. **功能完整性**：補齊主流有聲書 App 的基本功能

透過這些改進，AI 廣播劇系統將能提供更完整、更專業的使用體驗，特別是雙語支援的特色功能，將成為系統的核心競爭力。
